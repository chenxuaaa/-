# 塌缩 COLLAPSE

> 你的武器是引力本身 —— 把满屏黑暗，吸成一个点。

一个单文件、零依赖、打开即玩的太空幸存者动作游戏。WASD 走位，自动索敌射击；**按住鼠标左键在世界任意位置张开引力井把敌人拽向中心，松手塌缩，把它们连同整片战场一起压爆**。

![游戏截图](screenshot.png)

## 玩法

| 操作 | 作用 |
| --- | --- |
| `WASD` | 移动，射击自动索敌 |
| **按住鼠标左键** | 张开引力井，持续吸附范围内的敌人 |
| **松开左键** | 塌缩引爆，被吸住的敌人越多，伤害越高 |
| `Shift` | 冲刺，短暂无敌 |
| `Esc` / `P` | 暂停 |
| `M` | 静音 / 恢复（环境音与音效一起） |
| ``` ` ``` | 调试面板 |

主菜单右侧的两个小按钮：

- `操作 · 自动/触屏/鼠标` —— 强制指定输入方式。默认"自动"只在**同时**满足「主指针是手指」且「不能悬停」时才启用触屏界面，所以带触摸屏的笔记本不会莫名其妙长出摇杆。
- `闪光 · 开/关` —— 关掉塌缩时那一下全屏白闪（护眼，设置会存进档案）。

### 核心技巧

引力井张开时会把你自己的移动速度拖慢 58% —— 这是刻意的。你必须在「贪更多怪」和「别被打死」之间反复下注：

- 井边缘也有效，先开井聚怪，再往井里补第二个井位（点一下即移井）
- 冲刺会把逃跑的怪撞进井里
- 塌缩同时结算，**范围内敌人数量线性提升伤害**，所以「再等半秒」永远成立，而等待就是危险
- 蓄力到 **95% 以上**再松手是「完美塌缩」：伤害 ×1.55、震屏与音效更重，屏幕中央亮起金色 `PERFECT`。蓄力条满格前那一小段，是你唯一能主动争取的额外收益

## 内容

- **8 种敌人**：残渣、疾行体、重压体、裂变体、射手、环子、碎晶、精英「吞噬者」
- **深度系统**：每 38 秒翻一层，敌人更快更硬，第 3 层起出现精英
- **24 项局内演化**：分武器 / 引力 / 生存 / 异变四条线，稀有度三档，包含分裂井、反向斥力、黑洞拖尾等异变
- **9 项局外永久解锁**：用带回核心室的结晶购买
- **9 个里程碑**：达成即解锁
- **深渊循环**：击败深 6 的终点守卫后，可以带着这一局的构筑直接潜入下一层深渊。敌人生命 ×1.45/层、速度与伤害同步上涨，结晶收益 ×1.55/层
- **构筑评级**：结算页会根据你的演化分布给这一局定性——引力奇点流 / 弹道压制流 / 致密生存流 / 混沌混塔，或某条传说异变的专属名字
- 局内结算会回顾你这一局搭出的构筑

## 宇宙感

这游戏外面不该是"一块深色背景"，而应该是一片真的空间。

- **环境音**是一个持续存在的深空声场：三个几乎重合的低频振荡器靠微小失谐缓慢拍频，撑出空间的体积；过滤后的白噪声像星风掠过；每 4–10 秒会有一颗星辰在很远的地方敲响（A 大调泛音 + 3.2 秒混响尾巴）。潜得越深，这个空间越低沉。没有旋律，只有尺度。
- **星空**是三层视差：屏幕空间的远星（不随镜头移动）、世界空间的淡彩星云、随镜头移动的近景星。每颗星有自己的闪烁相位和速度，亮度按星等分布，偶尔一颗亮星会张开十字光芒。

### 触屏 / 手机

竖屏、横屏都能玩，且建议竖屏——手机竖着拿，两只手拇指落在下两角，摇杆和冲刺键正好在那里。
界面会自动切成触屏布局：判定条件是**同时**满足 `pointer: coarse` 与 `hover: none`，因此触屏笔记本不会被误判成手机。想强制切换，主菜单点 `操作` 按钮，或在网址后加 `?touch` / `?mouse`。

| 操作 | 作用 |
| --- | --- |
| 左下摇杆 | 移动（模拟量，推多少走多少） |
| **按住屏幕** | 在手指按下的位置张开引力井，持续蓄力 |
| **松手** | 塌缩 |
| 右下圆键 | 冲刺 |
| 右上 `Ⅱ` | 暂停 |

两只手各干各的：摇杆那根手指抬起不会打断正在蓄力的那一根（按 `pointerId` 追踪）。现在是竖屏优先设计，竖着拿视野最大；横屏当然也能玩。

镜头不是写死的倍数，而是按屏幕**短边**反推：短边恒定看到 640 个世界单位，所以小屏自动拉远、大屏自动拉近。竖屏时再多拉 24%——竖屏横向天生就窄，不拉远会被包围到看不见。实测手机竖屏可见 842×1351 世界单位，比横屏的 1250×597 多一倍实面积。转屏不需要刷新，每帧自对齐。

视野大了人口密度也得跟上：竖屏时敌人上限×1.45、每波数量×1.2。另外修了一个早期坑：刷怪距离之前用屏幕像素算但当成世界单位用，一旦拉远敌人就会在画面中间凭空出现；现在沿生成角度求椭圆边界，保证真在画外。

轻点一下不会炸：按住不足 0.16 秒就松手，系统当作误触直接忽略，既不塌缩也不进冷却。

## 运行

```
双击 index.html
```

浏览器要求声音必须由用户手势唤醒 —— 所以点一下"开始下潜"（或按任意键）之后，环境音才会在 5 秒里缓缓浮起来。

想让存档从零开始：用 `index.html?fresh` 打开一次即可清空。

## 流畅度

帧率几乎只取决于一件事：**画布有多少像素**。实测每百万像素约 1.6ms 的填充成本——340 万像素能跑 176fps，766 万掉到 71，1360 万只剩 46。而在 2 倍缩放的 2560×1600 屏上全屏时，画布正好是一千三百万像素。

所以画布分辨率不是直接取 `devicePixelRatio`，而是按**总像素预算**反推：默认上限 420 万像素，超出就自动降低渲染分辨率。发光画风下这点软化几乎看不出来，而 UI 是独立的 DOM 层、始终清晰。

机子较弱的话，用 `index.html?lowfx` 可以再降一档（240 万像素）。

真正把帧率拖垮的却是一个很不起眼的地方：**星星每帧都在拼字符串**。屏幕上有一千多颗星，旧代码给每一颗都拼一个 `rgba(r,g,b,a)` 字符串赋给 `fillStyle`，等于每帧上千次字符串拼接加颜色解析；`drawGlow` 还要再走一遍十六进制解析。现在星星按色温分成 4 批，`fillStyle` 每批只设一次，单颗亮度全部交给 `globalAlpha`；十六进制解析结果也缓存进 `Map`。这一项把帧时间中位数从 5.6ms 压到 1.1ms。

另外两处一起修了：

- `pointermove` 原本每次都读 `getBoundingClientRect()`，而蓄力条每帧都在改样式，布局永远是"脏"的 —— 高回报率鼠标每秒上千次移动就等于上千次**强制同步重排**。这就是"按住左键才卡、单纯晃鼠标不卡"的根因；现在画布矩形在尺寸变化时缓存一次，蓄力条也改用 `transform` 缩放。
- 引力井的黑核与亮核改成预烘焙贴图，不再每帧新建两个径向渐变；两次塌缩之间加了 0.12 秒冷却，疯狂连点不会再把每帧都变成一次全屏爆炸。

按反引号键（`）可以打开调试面板，能看到实时 fps、当前渲染倍率和画布尺寸——反馈卡顿问题时把这些数字发出来就够了。

## 技术说明

整个游戏是一个 121KB 的 `index.html`：Canvas 2D 渲染、WebAudio 合成音效、无任何外部资源与第三方库。所有美术都是程序化绘制的（光晕用预烘焙的径向渐变缓存，避免每帧 `shadowBlur` 掉帧）；环境音、混响（程序生成的脉冲响应）、星空也全部是实时合成，没有一个音频文件或图片资源。
